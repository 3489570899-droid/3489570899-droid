# 方块战场 · Block Arena

一个纯前端实现的 3D FPS 网页游戏，基于 Three.js，单文件、零构建、打开即玩。

## 在线试玩

下载 `fps-game.html`，用 Chrome / Edge 双击打开即可开始游戏。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` |
| 疾跑 | `Shift` |
| 跳跃 | `空格` |
| 视角 | 鼠标移动（Pointer Lock） |
| 射击 | 鼠标左键（按住连发） |
| 换弹 | `R` |

## 特性

- **第一人称射击**：射线检测命中判定，爆头 60 伤害 / 躯干 34 伤害
- **AI 敌人**：6 个机器人，具备巡逻、追击、视线检测（LOS）、走位与开火逻辑，阵亡后 3 秒自动重新部署
- **完整手感反馈**：后坐力、枪口闪光、曳光弹、命中粒子、屏幕受击红屏、走路视角摆动
- **HUD 系统**：血条、弹药（低弹量闪烁）、击杀播报、得分统计、阵亡与重新部署
- **程序化音效**：使用 WebAudio 实时合成，无任何外部音频资源
- **碰撞系统**：AABB 碰撞检测，支持掩体箱子与边界墙

## 技术栈

- Three.js r128（CDN 引入，无需 npm 安装）
- 原生 JavaScript（ES6+）
- HTML5 Pointer Lock API
- WebAudio API

## 说明

本项目为纯前端单机实现，敌人由 AI 模拟。若要做真正的多人联机对战，需要引入 WebSocket / WebRTC 服务端。
